# 🔐 PassOP - Password Manager

A full-stack password manager built using React, Express.js and MongoDB.

PassOP allows users to securely manage their passwords in one place with an easy-to-use interface.

## 🚀 Features

- Add and save passwords
- Edit saved passwords
- Delete passwords
- Show / hide passwords
- Copy passwords to clipboard
- Responsive user interface
- MongoDB database integration
- REST API using Express.js

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- JavaScript

### Backend
- Node.js
- Express.js
- MongoDB
